## 📖 About This Project

This repository is part of the **CS50x Persian** initiative, created to make high-quality computer science education accessible to **Persian-speaking learners**.

The project provides Persian-language resources for **Harvard University's CS50 Python**, helping students learn Python programming, problem-solving, software development, and programming fundamentals in their native language.

Through **CS50x Persian**, Persian-speaking students can access professionally translated educational content, course materials, exercises, and learning resources designed to make the CS50 Python curriculum easier to follow and understand.

Our goal is simple:

**To make world-class computer science education accessible to Persian speakers. ❤️**

---

## 🎓 About CS50 Python

**CS50's Introduction to Programming with Python** is Harvard University's course designed to introduce students to programming using the Python programming language.

Throughout the course, students learn the fundamentals of programming and develop the ability to solve problems through code, while gaining practical experience with Python and software development.

The Persian edition makes these concepts accessible to students who prefer learning programming and technical subjects in Persian.

---

## 📚 What You'll Learn

Throughout CS50 Python, you will learn:

* Loops
* File I/O
* Libraries
* Exceptions
* Unit Tests
* Conditionals
* Regular Expressions
* Functions, Variables
* Object-Oriented Programming

By the end of the course, you will have a strong foundation in Python programming and will be able to apply your skills to solve programming problems and build real-world software projects.
